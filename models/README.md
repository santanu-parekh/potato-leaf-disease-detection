# models/

Put your trained files here so anyone can run the Colab notebook without retraining:

- `potato_model.keras`
- `class_names.json`

Both are created by `train_model.py` (or by the Colab notebook, Option B).
On your PC they are in the output folder you chose when training, e.g. `C:\Users\Santanu\Desktop\Project_output`.
